# ✦ Voyara AI — Intelligent Travel Recommendation Engine

> **AI-driven travel intelligence platform** that surfaces real-time climate data, curated tourist attractions, and personalised hotel recommendations — powered by Claude AI, OpenWeatherMap, and OpenTripMap.

---

## 🧠 Overview

**Voyara** is a full-stack AI travel recommendation engine built with Python and Streamlit. Users enter any destination worldwide and receive an aggregated, real-time travel intelligence dashboard — combining live weather data, top attractions, accommodation options, and a deeply personalised AI travel report generated by Claude (Anthropic).

This project demonstrates production-grade API integration, AI-powered personalization, and premium UI/UX design — all within a Python-native Streamlit application.

---

## 🚀 Features

| Feature | Technology | Description |
|---|---|---|
| **Real-time Climate Data** | OpenWeatherMap API | Live temperature, humidity, wind, pressure, visibility |
| **Tourist Attractions** | OpenTripMap API + Nominatim | Geocoded attractions within configurable radius |
| **Hotel Recommendations** | Aggregated data layer | Tiered (Luxury / Premium / Boutique) with amenities |
| **AI Travel Insights** | Anthropic Claude Sonnet | Personalized itinerary, cuisine, insider tips, budget compass |
| **Interactive Map** | Folium + CartoDB Dark | Pinned attractions & hotels on live dark-theme map |
| **Personalization Engine** | Trip type, duration, budget | Claude tailors every insight to user preferences |

---

## 🛠️ Tech Stack

- **Language**: Python 3.10+
- **Frontend**: Streamlit + Custom CSS (Glassmorphism, Cormorant Garamond typography)
- **AI Engine**: Anthropic Claude Sonnet via `anthropic` SDK
- **APIs**:
  - OpenWeatherMap (climate data)
  - OpenTripMap (tourist attractions)
  - Nominatim / OpenStreetMap (geocoding)
- **Mapping**: Folium + streamlit-folium (CartoDB dark_matter tiles)
- **Deployment-ready**: `.streamlit/secrets.toml` for secure key management

## ⚙️ Setup & Installation

```bash
# 1. Clone the repo
git clone https://github.com/yourusername/voyara-ai.git
cd voyara-ai

# 2. Create virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Add API keys to .streamlit/secrets.toml
#    (see .streamlit/secrets.toml template)

# 5. Run
streamlit run app.py
```
